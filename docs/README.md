## Getting Started

To run the project locally, you need two terminals.

**Terminal 1 (Backend)**
```bash
cd backend
npm install
npm run dev
```

**Terminal 2 (Frontend)**
```bash
cd frontend
npm install
npm run dev
```

Ensure you have your `.env` files set up in both directories according to their respective `.env.example` files.
